# SEN306 – Software Construction

## 📘 Course Overview

SEN306 (Software Construction) focuses on the principles, tools, and practices required to design, build, test, and maintain high-quality software systems. The course emphasizes writing clean, maintainable code and applying modern development methodologies.

---

## 🎯 Learning Objectives

By the end of this course, students should be able to:

* Apply software construction best practices
* Write clean, modular, and maintainable code
* Use version control systems effectively (e.g., Git)
* Implement testing strategies (unit, integration, etc.)
* Understand and apply design patterns
* Collaborate in team-based software projects
